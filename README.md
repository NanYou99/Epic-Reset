## 🇨🇳 中文

### ✨ 特性

- **🔮 动态品阶**：根据护甲值自动判定稀有、传说、史诗、神话品阶。
- **⚔️ 随机词条**：每套装备自动生成独特的 2件套 / 4件套效果，不再千篇一律。
- **🧩 海量兼容**：自动识别并兼容市面上绝大多数护甲模组，无需配置。
- **📜 鉴定卷轴**：随机词条装备需鉴定后激活，增加探索乐趣。
- **🎨 智能配色**：词条品质分为白色（普通）、蓝色（稀有）、金色（极品）。

### 📦 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/) (>= 0.15.0) 和 [Fabric API](https://modrinth.com/mod/fabric-api)。
2. 将 `epic-reset-x.x.x.jar` 放入 `mods` 文件夹。
3. 启动游戏，享受史诗冒险！

### 🎮 玩法说明

- 装备第三方模组的护甲后，系统会自动识别套装并提供对应的属性加成。
- 使用**鉴定卷轴**（放副手 + 右键）逐件鉴定史诗/神话套装。
- 词条品质越高，属性越强——寻找金色词条的极品装备吧！

## 🇬🇧 English

### ✨ Features

- **🔮 Dynamic Tiers**: Automatically determines rarity (Rare / Legendary / Epic / Mythic) based on armor value.
- **⚔️ Random Affixes**: Each armor set generates unique 2-piece / 4-piece bonuses, never repetitive.
- **🧩 Massive Compatibility**: Auto-detects and supports most armor mods on the market — zero config.
- **📜 Identification Scroll**: Random-affix equipment needs identification to activate, adding exploration fun.
- **🎨 Smart Color Coding**: Affix quality divided into White (Common), Blue (Rare), Gold (Legendary).

### 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) (>= 0.15.0) and [Fabric API](https://modrinth.com/mod/fabric-api).
2. Put `epic-reset-x.x.x.jar` into the `mods` folder.
3. Launch the game and enjoy your epic adventure!

### 🎮 Gameplay

- After equipping armor from third-party mods, the system auto-detects the set and grants bonuses.
- Use the **Identification Scroll** (hold in off-hand + right-click) to identify Epic/Mythic sets piece by piece.
- Higher affix quality means stronger bonuses — hunt for gold-tier gear!
